# To be the champ, you got to ship the tasks!

##Background

As part of an AI Engineering course that I took I had to create a project management tool. 

https://www.udemy.com/share/10eOir3@Wk2I-1NRTKGUSHKDf5GC3SOC8739Ca1xISpEihQAeYDwW6l8znQGCgps74rAJSET/

I took the basic design and added some "Flair" to it.  Ric Flair to be exact.  The 16-time Heavyweight Champion of the World! 

##Capabilities

User can create, edit, delete, move Kanban cards. 
User can rename columns. 
User is flagged when a card exists past the due date.  
User is treated with a Ric Flair "Woooooo!" when a card is moved to a new column. 
User can utilize a *Digital Assistant* to perform all activities previously defined.  
     - Digital Assistant is powered via OpenRouter.ai API key.
